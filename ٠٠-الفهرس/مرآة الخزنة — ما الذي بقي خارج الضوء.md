# مرآة الخزنة: ما الذي بقي خارج الضوء؟

[[خريطة-المعرفة|خريطة المعرفة]] تقرأ العلاقات وتحكم عليها؛ هذه الصفحة لا تفعل ذلك. إنها مرآة باردة تتبدل وحدها كلما تغيّرت الملفات. قد تكشف ملاحظة تُركت طويلًا بلا مراجعة، أو سؤالًا صار له جواب في موضع آخر، أو جزيرة لا يدخل إليها رابط ولا يخرج منها.

الأرقام هنا لا تقرر قيمة النص. الملاحظة المنعزلة قد تكون بابًا لم يُفتح بعد، والملاحظة كثيرة الروابط قد تكون مزدحمة لا عميقة.

## النصوص التي تعلن حالتها

```dataview
TABLE WITHOUT ID
  file.link AS "الملاحظة",
  حالة AS "الحالة",
  آخر_مراجعة AS "آخر مراجعة"
FROM ""
WHERE حالة AND !startswith(file.path, "نظام-الزوايا-التسعة/")
SORT آخر_مراجعة DESC
```

## الأسئلة التي لم تُغلق

```dataview
TABLE WITHOUT ID
  file.link AS "خرج السؤال من",
  سؤال AS "السؤال المفتوح"
FROM ""
FLATTEN أسئلة_مفتوحة AS سؤال
WHERE سؤال AND !startswith(file.path, "نظام-الزوايا-التسعة/")
SORT file.name ASC
```

## الأبواب المؤجلة

```dataview
TABLE WITHOUT ID
  file.link AS "الملاحظة الأم",
  رابط AS "الباب المؤجل"
FROM ""
FLATTEN روابط_تحتاج_توسعة AS رابط
WHERE رابط AND !startswith(file.path, "نظام-الزوايا-التسعة/")
SORT file.name ASC
```

## الجزر الصامتة

هذه ليست قائمة حذف، بل دعوة إلى السؤال: هل عُزلت الملاحظة لأنها ضعيفة، أم لأنها أول أثر لقارة جديدة؟

```dataview
TABLE WITHOUT ID
  file.link AS "الملاحظة",
  file.folder AS "موضعها"
FROM ""
WHERE length(file.inlinks) = 0
  AND length(file.outlinks) = 0
  AND !startswith(file.path, "نظام-الزوايا-التسعة/")
  AND !startswith(file.path, "٠٠-الفهرس/")
SORT file.name ASC
```

> [!warning] حدود المرآة
> ترى Dataview الحقول والروابط، ولا ترى إن كان الرابط صادقًا أو تجميليًا. الحكم الأخير يبقى للقراءة.
