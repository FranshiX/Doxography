# مزامنة Doxography بين Windows وAndroid

## البنية

يعمل Syncthing بوصفه قناة المزامنة اليومية، بينما يبقى Git على الحاسوب مسؤولًا عن تاريخ التغييرات ورفعها إلى GitHub. لا تستخدم `git pull` أو `git checkout` في الهاتف بعد تشغيل Syncthing على الخزنة نفسها.

```text
Obsidian Android ← Syncthing → Obsidian Windows → Git → GitHub
```

## قبل الربط

- حُفظت تعديلات الخزنة ورفعت إلى `origin/main` في commit `26eab31` قبل تثبيت Syncthing على هذا الحاسوب.
- ثُبّت Syncthing 2.1.3 عبر WinGet، وأضيف معرّف الهاتف الذي أرسله صاحب الخزنة. قبول الحاسوب والمجلد من الهاتف واختبار الاتجاهين لم يُؤكدا بعد.
- حالة نسخة Android القديمة وتعديلاتها الحالية غير متحققة؛ الأفضل استقبال النسخة الأولى في مجلد فارغ مثل `Documents/Doxography`، ثم فتحه في Obsidian.
- لا تحذف مجلد `.git` من الهاتف في اليوم الأول؛ اتركه نسخة أمان ولا تستخدم أوامر Git داخله.
- لا تحذف الخزنة القديمة حتى ينجح اختبار المزامنة في الاتجاهين.

## إعداد Android

1. ثبّت **Syncthing-Fork** من مستودعه الموثوق أو F-Droid.
2. اسمح له بالوصول إلى مجلد الخزنة.
3. اجعل استخدام البطارية **Unrestricted** وعطّل تحسين البطارية للتطبيق.
4. افتح **Web GUI** أو شاشة الأجهزة، واقبل `Doxography Windows` أو أضف معرّف الحاسوب الآتي:

```text
26JDGGP-BPN7G5G-GDBT6KI-WAEGF4R-LMIC5J4-2467AGT-5FCQ35O-ICQPDQ2
```

5. عند وصول مشاركة `Doxography`، ذات Folder ID `doxography`، اختر المجلد الفارغ الجديد. إذا وجدت تعديلات خاصة بالهاتف في النسخة القديمة، احتفظ بها للمقارنة قبل أي دمج.
6. اختر نوع المجلد **Send & Receive**.
7. بعد وصول الملف `.stignore.shared` إلى المجلد الجديد، ضع في **Ignore Patterns** السطر الآتي. ملف `.stignore` محلي ولا ينتقل تلقائيًا؛ إدراج ملف مشترك قبل وصوله يوقف المسح حتى يوجد:

```text
#include .stignore.shared
```

8. انتظر حتى تصبح حالة المجلد **Up to Date** قبل فتح الخزنة في Obsidian.

## إعداد Windows

- نوع المجلد: **Send & Receive**.
- فُعّل **Staggered File Versioning** بحد أقصى 60 يومًا. يحفظ نسخًا مختارة من الملفات التي يستبدلها أو يحذفها تعديل وارد من الهاتف؛ التعديل المحلي على الحاسوب يحتاج تاريخ Git.
- مدخل التشغيل الحالي: `C:\Users\Administrator\AppData\Local\Microsoft\WinGet\Links\syncthing.exe`.
- مجلد الإعدادات المحلي: `C:\Users\Administrator\AppData\Local\Syncthing`؛ لا ينتقل إلى الخزنة أو GitHub.
- مهمة Windows باسم `Syncthing` تشغله في الخلفية عند تسجيل الدخول، ويوجد اختصار `Syncthing` على سطح المكتب.
- واجهة الإدارة المحلية: `http://127.0.0.1:8384`.
- أضيفت قواعد Windows Firewall للمزامنة والاكتشاف على الشبكات الخاصة فقط؛ واجهة الإدارة محلية. يمكن أن يستخدم الاتصال المرحّلات عند تعذر الاتصال المباشر.
- إذا أردت المزامنة المحلية حصرًا، أبقِ Local Discovery وLAN addresses وامنع Global Discovery وRelaying بعد نجاح الاختبار.

## حدود الملفات المتزامنة

تعمل `.stignore.shared` بقائمة سماح للمجلدات المعرفية السبعة و`٠٠-الفهرس` و`عقل-الدوكسوغراف` وملفات التشغيل المعروفة في الجذر. لا يُفحص محتوى المجلد المحظور ولا يُزامن ضمن هذا الإعداد التزامًا بقيود `INVOKE_AGENT.md`. إضافة مجلد رئيسي جديد تتطلب إضافته إلى قائمة السماح.

لا ينتقل `.git` ولا `.stversions` ولا إعداد `.obsidian` الخاص بكل جهاز. الملاحظات وروابطها تنتقل، ويمكن ضبط مظهر Obsidian وإضافاته على الهاتف بصورة مستقلة.

## اختبار الاتجاهين

1. أنشئ من الهاتف ملاحظة مؤقتة باسم `اختبار-من-الهاتف.md`.
2. انتظر ظهورها في الحاسوب.
3. أضف من الحاسوب سطرًا مميزًا إليها.
4. انتظر ظهوره في الهاتف.
5. احذف الملاحظة الاختبارية من الهاتف وتأكد أن الحذف وصل إلى الحاسوب وأن نسخة سابقة ظهرت في `.stversions`.

## قاعدة العمل اليومية

1. انتظر حالة **Up to Date** قبل تعديل الملاحظة نفسها على جهاز آخر.
2. لا تعدّل الملف نفسه على الجهازين في الوقت نفسه.
3. إذا ظهر ملف يحمل `sync-conflict`، لا تحذفه قبل مقارنة النسختين.
4. شغّل فحص الصحة من الحاسوب:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Test-Vault-Health.ps1
```

5. جرّب لقطة Git من غير حفظ:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Vault-Snapshot.ps1 -DryRun
```

6. أنشئ لقطة محلية يدويًا:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Vault-Snapshot.ps1
```

7. أنشئ لقطة وادفعها إلى GitHub:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Vault-Snapshot.ps1 -Push
```

## التراجع

إذا ظهرت مشكلة، أوقف Syncthing على الجهازين ولا تحذف أي ملف. احتفظ بنسخة Android القديمة، وافحص `git status` على الحاسوب وملفات `.stversions` و`sync-conflict` قبل اتخاذ قرار الاستعادة.
